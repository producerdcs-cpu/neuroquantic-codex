# CODEX Specification — Genesis

## Objetivo

Definir o contrato conceitual mínimo para que qualquer poema, pensamento, experiência ou enigma possa tornar-se um Códice estruturado.

## Estrutura lógica

```text
CODEX
├── identity
│   ├── id
│   ├── codename
│   └── title
├── content
│   ├── type
│   ├── original
│   └── language
├── context
│   ├── author
│   ├── timestamp
│   └── tags
├── perspectives
│   ├── poeta
│   ├── enigma
│   ├── arquiteto
│   └── lumen
└── relations
    ├── parent
    ├── children
    └── related
```

## Tipos iniciais

- `poema`
- `poesia`
- `pensamento`
- `experiencia`
- `enigma`
- `manifesto`
- `fragmento`
- `pergunta`

## Codinomes

O codinome funciona como uma camada narrativa e de descoberta. Ele não substitui o identificador técnico do Códice.

Exemplo:

`CODEX-000` → `GENESIS / 000 / LUMEN`

## Princípio multilíngue

O texto original deve ser preservado. Traduções futuras serão representações derivadas, nunca substitutos silenciosos do original.

## Privacidade e segurança

Não armazenar segredos, chaves de API ou dados sensíveis em Códices públicos. A futura camada de memória deverá possuir política explícita de retenção, exclusão e controle do usuário.
