# UX Genesis — Interface Cognitiva

## Objetivo

Transformar a interface inicial em uma experiência que comunique o conceito de perspectivas paralelas sem depender ainda de um modelo de IA externo.

## Fluxo principal

```text
ENTRADA DO USUÁRIO
       ↓
   INTENÇÃO
       ↓
┌──────┼───────────────┐
POETA ENIGMA ARQUITETO LUMEN TRANSLATOR
└──────┼───────────────┘
       ↓
  CONVERGÊNCIA
       ↓
     CODEX
```

## Princípios de interface

1. A entrada do usuário é o centro da experiência.
2. Perspectivas são apresentadas como lentes, não como respostas absolutas.
3. O usuário deve perceber que pode retornar, comparar e aprofundar uma mesma ideia.
4. O Códice deve preservar a origem do conteúdo.
5. O design deve funcionar primeiro em mobile e escalar para desktop.
6. A estética deve manter a identidade premium: azul profundo, dourado e atmosfera editorial/cósmica, sem prejudicar legibilidade.

## Próxima implementação

- painel de entrada;
- seletor visual de perspectivas;
- comparação de perspectivas;
- painel de convergência;
- criação de `CODEX-XXX`;
- histórico local no navegador;
- exportação futura;
- camada multilíngue posterior.

## Fora do escopo do Genesis

- autenticação real;
- banco de dados remoto;
- pagamentos;
- chamadas reais a LLM;
- memória persistente em nuvem;
- tradução por API.

Esses recursos entram somente nas fases correspondentes do roadmap.
