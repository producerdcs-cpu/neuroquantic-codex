# Privacidade — Public Preview

## O que a experiência atual faz

O NeuroQuantic Codex, nesta fase, é uma aplicação web estática/local-first.
Os registros da experiência e da memória atual são armazenados no navegador do
próprio visitante.

## O que não existe nesta fase

- conta de usuário;
- autenticação própria;
- banco de dados remoto do Codex;
- perfil comportamental centralizado;
- venda de dados;
- memória semântica em servidor.

## Atenção

Não inserir senhas, documentos, dados financeiros, informações pessoais sensíveis
ou outros dados que não devam ser públicos na experiência.

O GitHub Pages é um serviço público de hospedagem. O GitHub informa que o acesso
a um site Pages envolve registro do endereço IP para fins de segurança. Consulte
as políticas do GitHub para detalhes atualizados.

## Futuro

Se o projeto passar a coletar dados em servidor, será criada uma política de
privacidade apropriada antes da coleta, com definição de finalidade, retenção,
controle de acesso, segurança e direitos aplicáveis.
